# Original sewn-curve acceptance files

These original WeftForge files record the bounded UI-SEWN-CURVE-002 construction,
export and recovery workflow. They contain no imported garment or avatar assets.

- `before-split` is the actual saved two-panel cubic/reversed-seam state.
- `after-split` follows split t0.4 and one Undo/Redo. Both `after-invalid` files
  are byte-identical accepted construction after rejected edits.
- `coarse` and `fine` change only resolution/revision; OBJ/SVG files are actual
  native exports, with fine exports produced after process quit/relaunch/reopen.
- `quit-recovery-capture` is an exact byte copy of the native shutdown recovery
  before explicit recovery removed its sidecar. `recovered` has identical bytes.
- `recovered-edited` contains exactly the next revision and one control edit.
- The declaration, candidate manifest and quit records preserve original identities
  and observed preconditions. Technical times are host observations.

for source/executable hashes, fixed tolerances, exact checks and limitations.
