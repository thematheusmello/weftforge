# Static diagnostic strain replay

This AFTER-CLOCK packet validates commit
`2079411490512b3bdc13ae93774a2f48fb38cc1f`'s diagnostic arithmetic using already
public saved states. It supplies no new garment execution or physical acceptance.
The original source snapshots, harness, compiled comparison result and
unchanged-physics receipt retain their bytes. `PUBLICATION-PROVENANCE.json`
distinguishes those archived originals from the new portable adapter.

From a repository containing this packet at its intended publication location,
with CPython 3.13 and Rust 1.94.1 installed:

```sh
python3 parity/reports/artifacts/diagnostic-static-20261115/verify.py --repo-root .
```

The command reads the six existing case files and unchanged frozen `metrics.py`
under `parity/reports/artifacts/capsule-surface-20261115`; it duplicates no states.
It requires the five runtime sim source files to match the captured 2079411
hashes. A separate checkout can be selected with `--runtime-root CHECKOUT_ROOT`.
This option was used for preparation before the source change was integrated.
The checker rejects changed source or inputs and different exact f64 results.

The command regenerates input/expectation binaries, compiles the unchanged Rust
helper/harness and performs static measurement in temporary scratch outside the
repository. It constructs no Cloth and takes no integration steps. Scratch is
removed after the command; no binary inputs, axis outputs, executable or Cargo
target is distributed. `portable-replay.json` is one captured text receipt; its
wall time is a new posthoc measurement and never an original case clock.

Checks cover all 362 frozen maxima, signed values, triangle indices and axes,
plus 838,392 individual triangle/axis length-minus-one values. The 30 harness
self-checks cover affine extension/compression, grain rotation and winding,
exact dyadic translation, coordinate permutation/reflection, shared-edge equal
and near ties, unequal winners, compensated-sum rounding, non-finite sums and
stored unsnapped pi/2. The archived comparator's mutation checks reject incorrect
bits, attribution, state identity and missing axis values. The checker also
repeats the original unchanged-physics checks against already public 077 source:
constraint projection, solver step, cancellation, transaction acceptance,
validation, reset and common math remain byte-identical.

Archived `original-static/prepare.py` and `run_static.py` describe the original
private execution context; they are not portable entry points. Their old relative
bindings and binary digests remain historical records. Only selected text members
of the original static manifest are distributed here. Original compilation and
runtime receipts remain distinct from the new portable replay receipt.

The old actual cases still have 33 base and three height exact-attribution
failures, with both strict results false. Base still physically fails strain at
frames 28..37, peaking at 19.9092%; height's physical screens pass while its strict
result remains false. No evaluator, threshold, clock, garment or old result is
rewritten. This packet supplies no calibration, convergence, full CCD, native UI,
release acceptance or reference parity. Root owns formal registry/report updates,
tracked clean-checkout publication checks and combined integration gates.
