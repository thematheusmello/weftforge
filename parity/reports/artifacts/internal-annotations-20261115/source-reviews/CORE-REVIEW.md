Should fix

1. **The collinear backtracking safeguard lacks a decisive regression** (`crates/weftforge-core/src/geometry.rs:611–624`; test reach: `crates/weftforge-core/tests/internal_lines.rs:136–177`).

   - **What this is:** A cubic can fit inside a thin chord tube while turning back near an endpoint. The new control-projection guard correctly prevents treating flatness alone as proof that this boundary span is safe.
   - **Problem:** The new curved containment test uses monotonically ordered controls, so it does not exercise this safeguard. A concrete independent case is the unit-square bottom span from `[0,0]` to `[1,0]` with both controls `[1 + 5e-8, 0]`, plus the ordinary interior R annotation. Its endpoint derivative is `3 * (1 - (1 + 5e-8)) < 0`, so it reverses along the same line near its end; its controls are nevertheless less than `1e-7` from the chord. No current new test protects against accepting that self-overlapping span after an accidental removal of the projection checks. This is a test-coverage finding, not an observed acceptance defect in the reviewed code.
   - **Fix:** Add one small analytic rejection regression for that collinear cubic, with the existing atomic-failure assertion. Keep the approved flatness, clearance and work limits unchanged.
   - **If we skip it:** The implemented safeguard remains present, but a future simplification to flatness-only acceptance could pass the current R/L/C test set and silently weaken the certificate.
