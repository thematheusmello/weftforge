# Move a rest pattern in 3D

Select a visible pattern in Scene or click its surface in **3D Garment**. Turn
on **Move pattern**, then drag the selected surface to translate it along the
current view plane. Right or middle drag orbits the camera. With the mode off,
primary drag also orbits. Use **Reset** to return to the rest arrangement
after simulation.

Dragging previews the selected pattern. Releasing applies its translation as
one undoable edit. Press Escape before releasing to cancel. The current Snap
setting rounds the displacement along the world axes. Hold Alt or Option
when starting the drag to bypass Snap. The numeric **Arrangement** fields in
Properties provide precise X, Y and Z values and rotation.

The edit stores a placement in metres. The 2D pattern, seam relationships,
fabric and rotation retain their authored values. The studio rebuilds the rest
mesh at the new document revision.
