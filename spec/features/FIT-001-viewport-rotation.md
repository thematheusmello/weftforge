# Rotate a rest pattern in the 3D viewport

Select a visible rest pattern in Scene or click its surface in **3D Garment**.
Enable **Rotate pattern**. Start the drag on its surface away from the
center and drag around it. The center of the pattern’s authored 2D bounds
stays fixed in 3D. The camera direction at the start determines the axis.

Releasing the pointer applies one editable placement. Press Escape during
the drag to cancel. Undo restores the previous arrangement. The 2D outline,
fabric and sewing stay attached to the same pattern. The numeric rotation
fields in Properties use radians.
