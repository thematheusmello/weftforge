# Several cutouts in one pattern

A straight-sided pattern can carry several editable openings. Add hole accepts
a new loop inside the exterior. Each opening retains its ID, boundary curves
and vertices through edits, Undo, Redo and save/reopen. Selecting Remove hole
fills only that opening. Exterior sewing and the other openings keep their IDs.

All edges must clear the outside boundary and other holes by more than one
micrometre plus the existing numerical reserve. Crossing, touching, nested
and overlapping holes reject the complete transaction. Internal markings
must remain in material. The shared request budget applies to all of these
checks. The cloth mesh excludes each opening at every resolution.

SVG import accepts an exterior anywhere among its closed straight subpaths.
Editable holes retain their relative order and first vertex. The fill rule
controls accepted winding. SVG export writes one compound path per piece.
Separate exterior islands, curved cutouts and cutting through a hole are open.
