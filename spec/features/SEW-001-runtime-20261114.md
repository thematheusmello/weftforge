   name and the observed settings return. This supplies a bounded one-command

   `File > Open > Project` and select the saved original file. The observed
   low-space warning remains after the first Proceed action; the second Proceed
   completes reopening. This does not establish whether there were two distinct
   warning instances or delayed handling of one.
5. Select `Sewing > Edit Sewing`, then `Edit > Select All`. The same seam name,
   both 300.0 labels, directional marks and observed settings reappear. The
   native file hash and original curved input hash remain unchanged. The trace
   appearance differs across selection/reopen states; pixel/color identity is
   not a contract.

The process stays running throughout. This is **document close/open**, not a
process-restart test. The low-space warning also appeared when saving the new
working and result files; only owned original research files were used. The
resource checked by that warning is not inferred.
