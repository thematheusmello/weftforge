## Original construction and initial state

the observed Rectangle tool and a native canvas click. Initial controls again
show Width/Height 500/500 mm, link off, interval 750 mm, angle 90 degrees and
one shape. Enter Width 200 mm and Height 300 mm through keyboard replacement and
Tab, then explicitly enter interval **400 mm**, angle **0 degrees** and count
**2**. After OK, two rectangles appear vertically in this view. Their combined
selected boundary reports **2000.0 mm** in both 2D and 3D, and particle distance
is 20 mm. The controls do not establish a general replication angle or spacing
formula; angle zero must not be described as horizontal from this run.

Save the straight panels to a new private native file. Then use
`Display > 2D Pattern > Zoom Extents All` to frame both panels. The saved file is

`74e4a917989b31d8dfc37b1c1c32292c3310e38569f0294980fc81436736805c`.
Its internal format was not inspected. Native files can contain vendor resources

## Executed curve gesture and history

Select `2D Pattern > Edit > Edit Curvature`. Its toolbar label exposes the C
shortcut, but this run activates it through the menu. Drag the midpoint of the
upper panel's bottom edge outward once. The pinned, target-guarded public native
pointer route was used; it did not inspect or inject target code. One earlier
dry run refused because the target was not frontmost and posted no events.

The successful gesture used a freshly observed 2048 × 1209 pixel window image,
with window frame `[1,31,2207,1303]` in display points, and image points
`[1297,575]` to `[1297,610]`. The driver maps both axes using the actual image and
window extents. These screen coordinates describe this host observation, not a
portable authoring-coordinate contract.

The formerly straight **200.0 mm** edge becomes visibly curved. Its selected
2D and 3D lengths both display **206.9 mm**. One `Edit > Undo` restores a visible
straight edge and **200.0 mm**; one `Edit > Redo` restores the curve and
**206.9 mm**. Simulation stays off. The curve's exact control points, continuous
arc length, conversion formula and exported geometry have not been measured;
the one-decimal display does not support a 0.01 mm geometry tolerance.

This agrees with the documented entry behavior of
[Edit Curvature](https://support.marvelousdesigner.com/hc/en-us/articles/47358445809305-Edit-Curvature).
The official description is supporting documentation; the stated numeric
results come from this original runtime case.

## Executed first-side numeric interval

1. Select `Sewing > Free Sewing`. The 2D toolbar exposes Free Sewing (M), checked;
   the 3D toolbar also exposes a checked Free Sewing label. No M shortcut or
   3D canvas gesture is executed here.
2. Click the left endpoint of the new curved boundary. A cyan start marker and
   a zero-length preview appear.
3. Right-click while selecting the first side. **Create Sewing Line** opens with
   a Length stepper, printed **mm** unit, OK, Cancel and a close control. The
   initial Length is **90.6 mm** at this particular pointer position; it is not
   a default seam length.
4. Replace the selected value with `100`, commit with Tab, observe Length 100,
   then click OK. The first-side curve interval is marked and labeled
   **100.0**. The displayed difference is `100.0 (100.0 / 0.0)`. This establishes
   the entered first-side preview, not a completed two-sided seam.

The [Free Sewing manual](https://support.marvelousdesigner.com/hc/en-us/articles/47358239854361-Free-Sewing-2D)
documents choosing start/end points on each side, numeric entry through a
right-click dialog, and directional notches. Its general orientation and mismatch
rules still require controlled execution in this build.

## Unexpected second-side state and safe checkpoint

A guarded click intended for the other panel's upper-right endpoint was followed
by a 2D view in which both panels were outside the viewport. The cause is unknown.
Smart Panning is configured on, but that setting alone does not establish the
cause. `Display > 2D Pattern > Zoom Extents All` restored both panels and the
visible first-side interval. A subsequent right-click numeric-entry probe did
not open a modal. No completed seam or second-side correspondence was established.

One Escape attempt left the visible preview present. Keyboard delivery and
Escape cancellation behavior are unresolved; this is not a successful
cancellation claim. Selecting `Sewing > Edit Sewing` removed the unfinished
preview. Save As then retained a separate curved checkpoint, with Edit Sewing
selected, no selected object or modal, and simulation off. The native file is
62,298 bytes, SHA-256
`6d2280542cdccb84c09f46ef709c4c20e3152a01cf1fc42e775aff7b10edcffd`.
It has not yet been reopened or independently exported. The original straight
checkpoint remains unchanged.

Both saves displayed the same observed warning about less than 10 GB of available
space and possible file damage, and proceeded only for the investigator's new
original files. The underlying resource checked by the warning is unknown.
