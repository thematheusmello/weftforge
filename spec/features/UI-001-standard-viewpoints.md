# UI-001 standard 3D viewpoints

The View menu and Command search offer six orthographic views. Front and Back
look from positive and negative Z. Right and Left look from positive and
negative X. Top and Bottom look from positive and negative Y.
Command search keeps the query field visible while longer result lists scroll.

Front, Back and the side views keep Y up on screen. From Top, positive X is
screen-right and positive Z is screen-down. From Bottom, positive X is
screen-right and positive Z is screen-up. Depth increases toward the camera,
so drawing and picking use the same orientation.

**Default orbit view** restores the startup angles. Each command keeps 3D
zoom, 2D framing, selection, visibility and pending construction inputs. Mouse
orbit can start from the exact Top and Bottom orientations. Camera changes
apply to the local view while the editable project and simulation retain their
current state.

Check the three unit axes and depth from each orientation through both UI
entry points. On the native studio, capture the default, Front and Top views
of the same original garment. Verify the 2D pane stays pixel-identical and
returning to the default restores the 3D view. Custom saved views, camera
tracking, garment focus and reference workflow checks remain open.
