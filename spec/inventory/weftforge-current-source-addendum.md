File > New Empty and the New Empty command-search row queue the same post-inspector replacement action. A clean replacement creates Editor::default at revision 0 with no file path, selection, history or derived mesh/cloth, cancels the old worker and retains session view/snap settings. Dirty accepted work, pending or invalid numeric input, unfinished construction and an active autosave cause a retained-state refusal. This native session action is distinct from CLI new/MCP project_create file creation and adds no Command variant. Unfinished internal-line creation/endpoint state also blocks clean New Empty; successful replacement clears those revision/owner/target-bound previews. An unfinished first cut anchor or modal review also blocks clean New Empty. Accepted tool/owner/history/open/recovery lifecycle changes discard stale cut drafts; failed IO and New refusal retain still-valid state. An open hole review also blocks clean New Empty; accepted replacement clears that transient owner/revision/epoch-bound state without publishing its candidate. The existing cut-review state also owns a transient default-off sew option; New Empty refusal and accepted lifecycle reset do not publish that clone-only candidate.
